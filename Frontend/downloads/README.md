# Wangari Desktop App Downloads

The public download page uses `download.php?platform=windows`.

For production, upload the Windows installer to `Frontend/downloads/releases/` with this exact name:

`Wangari Farm Manager Setup 1.0.0.exe`

The endpoint also detects the local `dist-electron/` build during development. macOS and Linux buttons remain disabled until their release files are published and registered in the endpoint.
