# HTML Head & Metadata Reference

## Required Meta Elements
- `title`: Template `%s | Wangari — Smart Farm Management`
- `description`: Actionable summary under 160 characters
- `canonical`: Absolute URL `https://wangari.imeantech.com`
- `openGraph`: `og:title`, `og:description`, `og:image`, `og:url`, `og:site_name`, `og:locale` (`en_KE`)
- `twitter`: `summary_large_image`, title, description, image
- `robots`: `index: true`, `follow: true`, max snippet & image preview settings
