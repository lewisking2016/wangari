## Core Behavior Skills

### Ponytail (write minimal code)
**Path:** `ponytail/SKILL.md`
**Rule:** YAGNI ladder — skip, reuse, stdlib, native, one-liner, then minimum code.
**Always:** Code first, 3-line max explanation, fewest files/shortest diff.

### Ponytail Review (find over-engineering)
**Path:** `ponytail/REVIEW.md`
**Rule:** Review diffs for unnecessary complexity. One line per finding.

### Caveman (terse prose)
**Path:** `caveman/SKILL.md`
**Rule:** Drop articles, filler, pleasantries. Fragments OK. Direct answers. No tool-call narration.
